# --- rich text, by keyboard and by the bar ----------------------------------
# Select the last four characters of scene 1 ("now.") - the text node the tag
# anchor left behind, hence the walk rather than firstChild. That text node
# can carry a trailing zero-width caret spot ensureTrailingCaretSpot() left
# after the tag anchor (see 04-richtext.js) - real, invisible DOM the caret
# needed a place to land in while "now." was typed, stripped back out by
# syncFieldFromDom() before anything is saved. Counting the raw last four
# characters would land on it and clip the "n" off the selection, so the
# walk back from the end skips it rather than counting it.
