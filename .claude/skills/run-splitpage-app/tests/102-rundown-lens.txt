# the scenes near the pointer grow to a readable width and the rest shrink
# to make room, so a 3-second scene in a long script can be read and hit.
# The layout math is src/test/rundown.test.mjs; this is the page: an
# 80-scene document opened through the real open path, the pointer moved
# with PointerEvents (pointerType "mouse") on the track, since the driver
# has no hover of its own — then a real click, which is a real mouse at
# that point.
#

# #170 overlay fade while lensed and rundownX() answers in lensed pixels;
# b-roll ticks and the playhead move with the blocks; a slow move keeps the
# scene under the pointer; leaving puts every block back exactly; keyboard
# focus opens the lens on the focused block; reduced motion lenses without
# the glide; a touch never lenses; the condensed header lenses too.
