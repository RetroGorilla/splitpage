# left" (the hatching then does not repeat the delta), tally red once over.

# the blocks are laid out short of it, so it never covers one, under the

# whole. A click opens the reading speed and target popover (promptForWpm).
# The placement arithmetic is src/test/rundown.test.mjs (rundownLengthPlace);
# the phone's home for it (the header's status line) is suite 106.
#
