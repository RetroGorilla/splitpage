# Other people on the rundown strip (issue #202, 05p-rundown-presence.js):
# a dot in each person's colour on the block of the scene their caret is
# in, their name on hover, side by side when two share a block, an empty
# ring once they have been idle a minute, gone when they leave, following
# its block under the lens, on the thin bar too, and a click on one going
# to that scene. Nothing at all for a document that is nobody's session.
#
# People are faked the way tests/44-presence.txt fakes them: through
# window.__presenceTest.apply(), as the server would have answered. The
# beat keeps running while the session is hosted, and against this static
# server it would fail three times and clear everyone, so /api/presence is
# answered here from window.__here (and counted) — nothing else is faked.
# The idle minute is aged with window.__rundownPresenceTest.age().
