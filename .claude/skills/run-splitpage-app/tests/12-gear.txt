# Blur explicitly. jsclick (used below to work the panels) fires a synthetic
# click without moving document.activeElement the way a real click does, so
# without this the cell stays "focused" through everything that follows. That
# is not just cosmetic: renaming this same item from the panel later leaves
# state correctly updated, but render() rebuilding #rows then DETACHES this
# still-focused, now-stale node, and the browser's own blur/focusout on a
# detached element fires with the OLD pre-rename content — which
# onRootFocusOut duly syncs straight back over the rename. A real click
# blurs the cell as part of the click itself, well before any of that, so
# this exact corruption is a harness artifact, not a real bug - but it cost
# real time to prove that, so: always blur what `press` focused before using
# jsclick on anything that might re-render #rows.
eval document.activeElement.blur()
