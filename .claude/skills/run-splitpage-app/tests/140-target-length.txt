# A target length per script (#170, src/js/05t-target.js).
#
# Set from the clock's popover (the reading speed's box, #193) — a field
# taking the scene-length forms Adam signed off (1:30, 90, 90s, 1m30), six
# presets and "No target" — or from the command menu's "Set target
# length…". With one set the clock reads "01:35 / 02:00" and "0:25 left"
# (dim) or "0:05 over" (tally red); the rundown strip spans max(target,
# total) + 10s and draws a dashed line at the target, "Target 2:00", and
# hatching over the gap (or over the blocks past the target). One undo
# step; saved in the file; the overlay fades under the hover lens and comes
# back to scale; the thin bar keeps a tick; read-only in a review session.
# The value, the merge and the formats are src/test/target-length.test.mjs.
#
# Every `eval` is one physical line (the driver splits on newlines).
