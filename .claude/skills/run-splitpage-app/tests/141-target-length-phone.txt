# A target length on the phone (#170): the script's length, which on a
# phone is the last item of the header's status line (#207, Adam's call;
# the program clock's chip until then), reads "1:35 · 0:25 left" and fits
# with nothing wider than the screen; the popover opens on screen below it
# with 16px fields and finger-sized presets, a tap on a preset sets it, and
# the compact strip (no ruler) keeps the line, its "Target" label and the
# hatching on its 22px blocks, with no length label of its own. Its own
# suite: device metrics are set once, before the page loads.
#
# Every `eval` is one physical line (the driver splits on newlines).
