# `thumbnailsOnBeatClick`, the click route in src/features/gallery/mount.ts), against a FAKE host
# (window.__videoTest.setFetch; the drivers' __splitpageNoRemote keeps everything else off the network):
#   * nothing is fetched when the document opens or while typing; a click in a beat fetches for that beat's
#     own link only, and the thumbnail lands as a "Thumbnail added" edit with its own undo step and a toast
#     with Undo, the same as the Retry thumbnail button;
#   * the caret is left where the click put it, and typing on goes into the same cell;
#   * a link that failed is not asked for again on later clicks, and a failure says nothing; the manual
#     Retry thumbnail button still works for it;
#   * a click on the beat's tile opens the viewer, which shows the thumbnail once it arrives;
#   * nothing is fetched with video thumbnails off or while the browser is offline, and neither is
#     remembered as a failure; a link that is not YouTube or Vimeo is never fetched.
