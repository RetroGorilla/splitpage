# Every kind of edit to the script is saved by autosave (#208), part 1: the
# script itself. 186 is the side panels, comments and the gallery; 187 the
# hosted document and the words the status uses.
#
# "Saved 43 min ago" was only ever honest if every edit marks the document
# dirty (markDirty, 12-dirty-toast.js): that is what arms the autosave
# timers (scheduleAutoSave, 14-export.js), so an edit that skipped it would
# sit unsaved under a "Saved" label until something else wrote the file.
#
# The file is a fake FileSystemFileHandle, as in 28-autosave.txt, over a
# .splitpage so what was written can be read back as JSON. Autosave's pause
# is shortened to a few milliseconds. For each edit:
#   * the status goes Unsaved changes → Saving… → Saved (a MutationObserver
#     on #save-status keeps every text it is given, however briefly), the
#     header says "Saved just now", and the file was written again;
#   * what was written holds the edit;
#   * a moment later nothing has moved under the "Saved": what is on disk is
#     exactly what the page would write now (__same) — so nothing the app
#     did after the edit (a b-roll line anchored, a registry healed) was
#     left unsaved.
# Every `eval` is one physical line.
