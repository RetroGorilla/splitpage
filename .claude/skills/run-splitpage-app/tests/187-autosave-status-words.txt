# other places a document is saved to.

# "Saved 43 min ago" read as "autosave last ran 43 minutes ago", as if it
# had stalled. Now the header says "Saved just now" for the first minute
# after a write and then "All changes saved"; the time is in the tooltip
# ("Last saved to <where> at 2:52 PM", in the person's own clock — 133
# covers the 12/24-hour setting), and "where" is right for each target:
#   * a browser file (a fake FileSystemFileHandle): its name;
#   * the desktop app's file target (window.__desktopTest's fake bridge, the
#     same one 21-desktop-shim.txt drives): its name;
#   * a hosted document (window.__hostedTest.setSession, and PUTs to
#     api/docs/ answered by a fake, as in 54-server-conflict.txt): "the
#     server" — with typing, a status click and a comment each going out.
# A document just opened is "All changes saved" with no time (nothing was
# written by this page), and opening another straight from "Saved" no longer
# carries the first one's time over. Every `eval` is one physical line.
