# Selecting whole scenes by dragging out of a text box, and copying,
# cutting, deleting and pasting them (#204; src/features/clipboard/scene-select.js,
# src/features/clipboard/scene-clip.js):
#
#   * a drag that stays in its text box selects words, as ever; one that
#     leaves the box (up or down) selects whole scenes — the text
#     selection dropped, the scenes highlighted as a block (both columns),
#     the page scrolling near the window's edge;
#   * Ctrl+C / the right-click menu put the scenes on the clipboard in
#     Splitpage's own type (everything: comments, status, b-roll, gallery
#     pictures with their bytes) plus a two-column table and labelled
#     plain text for other programs;
#   * a paste into another document brings them in as new scenes after the
#     caret's scene, one undo entry, with fresh comment ids;
#   * cut and delete are one undo entry each; Esc and a click clear;
#   * a review session selects and copies, and refuses cut, paste and
#     delete;
#   * the grip still drags one scene to a new place (#185).
# The payload itself is src/test/scene-clip.test.mjs. Every `eval` is one
