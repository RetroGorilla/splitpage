# Document identity (02b-doc-id.js): state.docId, its hashing, its ingress
# rules, the Save As fork, the duplicate-id reassignment (orchestrator
# overrides.md #1: it never writes the user's file) and the browser's
# best-effort duplicate check over a fake BroadcastChannel.
#
# Neither file picker nor a real Electron shell can run headless, so this
# drives window.__splitpageFormats (20d-formats.js, the same trick
# 17-formats.txt plays) and window.__desktopTest (20f-desktop.js, the same
# trick 21-desktop-shim.txt plays) directly.
#
# The pure half of 02b-doc-id.js no longer lives here: the SHA-256 vectors,
# the deriveDocId golden value, the hostile-id cases, the mergedDocId truth
# table and decideDuplicateLoser moved to src/test/doc-id.test.mjs, which
# imports the module and needs no browser at all (#67). What is left is
# everything that only means something inside a running page.

# The fork is thrown away with the failed write, so the picked file must not
# become the Save target either: otherwise the very next plain Save writes
