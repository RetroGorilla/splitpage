# openFixture(id, title): serialize the CURRENT document under a chosen id
# and title, then reopen it as a .splitpage project — the home becomes a
# 'splitpage' file (F.docFile().kind, never pristine again) and the id is kept verbatim
# (migrateDocument keeps an already-valid embedded id).
#
# ONE FILE NAME for every fixture in this suite, deliberately. The browser's
# duplicate-document check (02b-doc-id.js) compares (docId, file name) across
# same-origin pages, and a name is all it has to go on: two pages holding one
# id under two DIFFERENT names read as two copies and the loser is re-id'd,
# which is exactly what the two-instance race case below would otherwise
# trip. The same name reads as the one file open twice, and is left alone.
