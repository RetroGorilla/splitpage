# A scene cut and Ctrl+Z (src/features/clipboard/scene-clip.js isMove, features/clipboard/scene-select.js
# pasteClip). Whether a paste of cut scenes is the MOVE (the same rows, their
# comments following their words, the b-roll keys finding their records) or a
# COPY (everything its own) must follow the undo stack:
#
#   * cut, paste in the wrong place, Ctrl+Z, paste again: still the move —
#     not fresh row ids, the comments copied with the originals left "No
#     longer in script", and the shot's record orphaned beside a new unshot
#     one (all autosaved);
#   * cut, Ctrl+Z the cut (the scenes come back), paste: a copy whose
#     comments are its own — not the originals' marks in a second scene,
#     which deleting the comment then left behind;
#   * a paste of the same cut once its scenes are in the script again is a
#     copy.
# Real mouse drags and real keys. The model is src/test/scene-clip.test.mjs.
