# The header's Collab button and the toolbar's labels (PR #233, Adam:
# "Add a button to the header, but we'll need to make the gear/production/
# b-roll/comments buttons condense when the window is narrow. But they
# should expand to show their names when you hover your mouse over them.")
#
# Collab is File ▸ Collaborate… beside Write and Present: the same dialog,
# the same "can it work" (updateCollaborateMenu, 13b-collaborate.js), and
# for someone on a link it is aria-disabled with the reason as its tooltip.
#
# The condensing is the one #174 made — the panel toggles' labels close
# below 1300 (1250 until Collab took 100px of the row), Write's below 1000
# (and now Collab's with it) — but closing
# and opening are a width animation on the motion tokens instead of a snap
# (the label used to leave the layout in one frame, the right half jumping
# by its width), and a closed label opens again on hover or keyboard focus,
# over its neighbours without moving any of them (app.css, "the toolbar's
# labels"; 20i-topbar.js measures the widths).
#
# Laid out the way 85 and 252 do it: the app a second time in an iframe on
# this page, the IFRAME resized (a suite can set the device metrics only
# once), its own media queries answering to its width. For the sweeps the
# iframe's motion tokens are set to 0.01ms (as 150 does), so each width is
# read settled; the animation checks put them back.
#
# Every `eval` is one physical line.
