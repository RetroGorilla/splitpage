# Menu commands behind a dialog, the writer, Present, the shot-list page or
# the tour. The desktop app's native menu items and their accelerators reach
# the page as one call, D.runMenuCommand (desktop/main.ts sendMenuCommand,
# 20f-desktop.js runDesktopMenuCommand), which runs the action through
# nativeMenuRunner (src/legacy/native-menu.ts), or clicks the File menu item
# of an export format. Each command is refused under what it would act
# behind, with a toast that says why, instead of acting behind it (#273,
# #274). When more than one is open the toast names the one in front: a
# dialog. The in-page shortcuts refuse under the same things, silently. The
# file pickers are replaced so nothing waits on a real one. __tidy() starts
# each section clean, so a command that acted where it should not have fails
# only its own checks.
