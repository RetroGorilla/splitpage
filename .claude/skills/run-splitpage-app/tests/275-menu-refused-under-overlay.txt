# Menu commands behind a dialog, the writer or Present. The desktop app's
# native menu items and their accelerators reach the page as one call,
# D.runMenuCommand (desktop/main.js sendMenuCommand, 20f-desktop.js
# runDesktopMenuCommand), which clicks the File menu item or the header's
# Save. Each command is refused under the same things its own shortcut
# already refused under, with a toast that says why, instead of acting behind
# them. The file pickers are replaced so nothing waits on a real one.
# __tidy() starts each section clean, so a command that acted where it should
# not have fails only its own checks.
