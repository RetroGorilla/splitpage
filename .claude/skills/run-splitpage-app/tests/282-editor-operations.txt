# Selected editor operations and what each one leaves behind (4.0 milestone
# 1, pinned before milestones 2 and 3 move them into the document core and a
# session): typing a word, Alt+Enter split, Ctrl+Enter new scene, Ctrl+B on a
# selection, the status dot, deleting an empty scene and Alt+Arrow moving a
# scene. For each: the rows it leaves, ONE undo entry, where the caret ends
# up, and Ctrl+Z (and for typing Ctrl+Y) putting it back. Typing, the first
# edit, marks the document unsaved; the others start from an unsaved document.
# Undoing back to the rows it was opened with leaves it unsaved, as it does
# today (checked after the first Ctrl+Z and again at the end). Passes against
# the code before the action registry (4.0-development 47c0309) and after it.
# Every `eval` is one physical line.
