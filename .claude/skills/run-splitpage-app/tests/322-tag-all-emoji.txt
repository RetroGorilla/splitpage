# at 80 UTF-16 units can end in half an emoji, and the Production panel's
# "Tag all N mentions" then tags a range that ends between the two halves.
# The tag takes the whole emoji, so no half is left in or out of the tag.
#
# Every `eval` is one physical line (the driver splits on newlines).
