# Hide shot scenes (issue #25): a reading toggle, not a document edit — every
# scene marked Shot collapses into one "N shot scenes hidden" strip between
# the scenes still open, remembered per device (localStorage), never dirtying
# the document. Find & replace, comments "jump to" and tag "jump to" all
# expand a hidden run rather than silently failing to find their target, a
# scene that turns Shot while visible gets a short grace before it collapses,
# and the split view, the writer and the teleprompter all agree on what is
# currently hidden.
#
# Everything here drives the app the way a person would — clicks and real
# key events — rather than reaching into `state`, which is private to the
# app's own closure and unreachable from a driver script.
