# The hosted client's half of image blobs (#82 P5, 13-hosted.js; the server
# half is server/server.js, tested by tools/test-server.mjs).
#
# Nothing in the app creates an `imageRef` yet — that is the later schema
# switch — so the states here are given refs by hand: a row's
# `imageRef: {sha256, width, height, mime}` and a comment body's
# `<img data-blob="<sha>">`, with the bytes put in the page's registry
# through window.__blobsTest (02c-blobs.js) from real canvas PNGs.
#
# The harness cannot start server.js, so `fetch` is replaced for every URL
# with `api/` in it, the way 54-server-conflict.txt and 57-review-comments.txt
# replace it: a small emulator of the routes this touches (health, me,
# presence, blobs/missing, blobs/<sha> PUT and GET, the document PUT and the
# comments POST), recording each call in order with its
# `x-splitpage-client` header and its status. What it pins:
#
#   * every API call carries `x-splitpage-client: 2` — except to a server on
#     another origin whose preflight refuses it (older than #82), which is
#     asked again without it and remembered per connection;
#   * a server whose /api/health has no `blobs` is sent images INLINE
#     (data: URIs) and never sees a blob call; the page keeps its refs;
#   * against a blob server a save is  missing -> PUT blob -> PUT document,
#     in that order, and a second save uploads nothing;
#   * a 422 missing-blobs uploads what it lists and retries once;
#   * a 422 for bytes nobody has retries with `acceptMissing`;
#   * a reviewer's comment with an image: missing -> PUT blob -> POST; a 429
#     review-budget is a toast about the image allowance and the comment
#     waits; an image nobody has is a refusal, never `acceptMissing`;
#   * the blob fetch helper re-hashes what the server sends and refuses a
#     body that is not the image asked for, and the registry's ensureBytes()
#     reaches the server through it once its own store has nothing;
#   * 426 client-too-old is "reload this page", once, with no retry loop.
# Every `eval` is one physical line.
