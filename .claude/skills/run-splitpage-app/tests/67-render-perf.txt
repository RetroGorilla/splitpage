# What typing and a structural edit cost in a long script (issue #84).
#
# render() reconciles #rows by row id instead of rebuilding it, renderRow()
# repaints one row's changed parts, and the breakdown is one production
# index derived lazily and shared by everything the one idle refresh runs.
# window.__renderTest (05-render.js) counts full renders, rows and fields
# repainted, production-index derivations and idle refreshes; this suite
# reads them around real gestures on a 300-scene document:
#
#   - typing into one cell with real key events does no full render and
#     repaints no row, and each idle refresh derives the breakdown at most
#     once — however many jobs (badges, runtime, untagged scan, b-roll)
#     it ran; prose derives it not at all, and closing a tag once;
#   - a structural edit somewhere else (insert, move, delete — driven with
#     jsclick, which leaves focus where it is, as a server merge landing
#     mid-sentence would) leaves the focused cell focused, the same DOM
#     node, with the caret at the same offset, and every untouched field
#     in the document the same node it was.
