# Undo and redo for the whole document (#85, src/js/12a-undo.js).
#
# One stack per tab, recorded by diffing the document after every edit, so
# every action is covered without its own undo code: typing (a word at a
# time), a deleted scene, a status click, a split. Ctrl+Z / Ctrl+Shift+Z /
# Ctrl+Y answer from a script cell and from anywhere that is not a text box
# of its own; the browser's own contenteditable history is never used
# (historyUndo is cancelled). The pure core is src/test/undo.test.mjs.
#
# Every `eval` is one physical line (the driver splits on newlines).
