# Editing a comment or reply draft through the document model, with an
# undo history of the box's own (#85 design §10 step 7;
# src/js/05d-draft-edit.js, wired in 05-render.js and 22a-editor-wiring.js).
#
# The composer and the reply boxes used to be edited with execCommand,
# which kept the browser's own undo working in them. Now B/I/U/S,
# highlight, a link, Enter, a paste, a picture and a video card are edits
# through the model, and Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y (and a menu's
# historyUndo) answer from the box's own history, so undo must still cover
# typing, formatting and pasting there — and every picture in the draft
# must survive every edit. The pure half (placeholders, the history stack)
# is src/test/draft-edit.test.mjs.
#
# Every `eval` is one physical line (the driver splits on newlines).
