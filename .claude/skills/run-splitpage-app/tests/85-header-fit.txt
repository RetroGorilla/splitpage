# (#175), the panel toggles, Write and Present. (The program clock was in
# the middle of the row until #207; the script's length is at the end of
# the rundown now, which #190's check below finds on the strip.) An overflow there is
# not clipped and not counted in scrollWidth (it spills out of a flex-end
# box), so this compares bounding boxes, pairwise.
#
# The widths come from #174 (761 800 900 1000 1100 1240 1280), #183 (1440
# 1920) and #190 (2560 3440). A suite can set the device metrics only once
# (SKILL: changing them mid-session aborts the CDP socket), so the app is
# loaded a second time in an iframe on this page and the IFRAME is resized:
# its media queries answer to its own width, the same as a window's, and
# its layout is read straight out of its document (same origin).
#
# Then, at the widths each issue names:
#   #183  a 60-character title ends in "…" (it is cut short: scrollWidth >
#         clientWidth) with the whole of it as the tooltip, your name is
#         visible, unobstructed and the element at its own centre (so it is
#         clickable), and clicking into the title gives the whole title back
#   #166  opening each panel changes neither the header's height nor its
#         left edge, nor the File button's place
#   #190  at 2560 and 3440 the row runs from the window's left edge to its
#         right, with or without a panel, and the script is still 1800px
#         (1760 of #rows plus its rows' 20px either side), centred
#   #189  the rundown strip runs the window's width with no panel, and to
#         the panel's left edge with one
#   #187  one slim scroll-bar style everywhere; the page's own bar goes
#         while a panel is open
#   #188  an open panel's right edge is the window's, its top the row's
#         bottom edge
#   #175  Search is there at every width, the field on a wide window, the
#         word and its keycaps a step down, the magnifier below 1600 and on
#         a phone width
#
# Every `eval` is one physical line (the driver splits on newlines).
