# "Use Chromium Speech Recognition" (issue #123) is no longer offered (#1163).
#
# The desktop app reads in a browser one way: Present ▸ Present in browser…
# (58-prompter-open-in-browser.txt). The Chromium entry left the File drawer
# and the command menu; this suite holds that it stays gone, in the browser
# build and under the in-memory fake desktop backend (20f-desktop.js), whose
# bridge still answers the old call. Main's half, which is kept, is
# desktop/test/smoke.mjs's "present in chromium" group.
#
# Every `eval` is one physical line (the driver splits on newlines).

expect !window.__commandTest.results('chromium').some(function(g){ return g.items.length > 0; })

wait F.docFile().name === 'chromium.md'

wait !document.getElementById('file-menu').hidden

wait document.getElementById('file-menu').hidden
