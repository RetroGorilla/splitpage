# Pictures and videos pasted or dropped into a script cell attach to the
# scene (#124; 05c-clipboard.js pasteIntoCell/readClipboardFiles,
# 21-events.js insertIntoScriptCell/announceAttached). A script cell still
# holds only words (#85 design D7), but what it will not hold is no longer
# thrown away: each picture, video card, video link or video file becomes
# a comment on that row and column —
#   * a video link pasted on its own (the address bar's plain text), or a
#     video card, attaches a video card and puts nothing in the cell;
#   * words that come with a picture and a video go in as usual, and the
#     words, the picture and the video are ONE undo entry;
#   * a link to a video inside other words stays in the words and is
#     attached too;
#   * a picture file (with the HTML naming it by web address, as a copied
#     image carries both) attaches the file's picture once, by sha; a video
#     file is named in a comment; a picture only linked to the web is not
#     kept, and a toast says so;
#   * a drop does the same, a video file dropped on the visual column goes
#     to the scene rather than being taken for its picture, and an image
#     file dropped there still IS the scene's picture;
#   * the toast says "… attached to scene N" and its Undo takes the paste
#     back, words and all — unless something else was done since.
# Every `eval` is one physical line.
