# The b-roll panel, one line per shot (#148, src/js/08d-broll-panel.js):
#
#   * how the list is looked at — the filter chips and the Group menu — is
#     remembered per device in localStorage, survives a reload, and never
#     touches the document: nothing dirty, nothing on the undo stack;
#   * the summary ("3 of 8 shots in the can") and a bar with one segment
#     per shot, teal shot, paper to shoot, red flagged;
#   * a line per shot about 52px tall: a checkbox, the name, and under it
#     the location, the person (initials) and the props — the script's
#     tagged ones and the hand-added ones; a flag and a note icon; no
#     "Scene N" chip and no "No audio reference." placeholder;
#   * scene groups headed "Scene 03", the scene's audio in italic and
#     done/total; shots with no line group as "Added here";
#   * the checkbox marks a shot Shot / To shoot in one click, one undo;
#   * opening a shot shows the label–value card, with Rename and Delete in
#     its ⋯ menu, and a location and a note set there land on the record;
#   * Ctrl+click and Shift+click select lines, the dark bar changes them
#     all at once, and each change is ONE undo step; Esc clears it.
# Every `eval` is one physical line.
