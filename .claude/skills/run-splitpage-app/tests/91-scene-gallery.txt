# A scene's Image section is a small gallery (#135; 02d-gallery.js, the
# carousel in 05-render.js rowGalleryHtml, its controls in 21-events.js):
#   * a scene with three pictures shows one at a time with "1 / 3" and
#     ‹ ›, which wrap; ← / → on its controls step it too;
#   * each picture's caption holds its video links — an address as a link,
#     a video file by its name (escaped) — never the scene's words; a link
#     opens through the desktop bridge's openExternal on desktop, in a new
#     tab in the browser; a thumbnail marked as its video's opens it too;
#   * Add puts a picture beside the others and shows it, Replace swaps the
#     one on screen keeping its caption, Remove takes that one away, × takes
#     a link off — each one undo step;
#   * a .splitpage save carries every picture inline and reopens as the
#     same gallery.
# The model, merge, and exports are src/test/gallery.test.mjs; pastes and
# drops are 92-paste-into-gallery.txt. Every `eval` is one physical line.
