# Pictures and videos pasted or dropped into a scene go into its gallery,
# the Image section (#135; 05c-clipboard.js pasteIntoCell/attachToGallery/
# readClipboardFiles, src/bootstrap/wiring/editor.ts insertIntoScriptCell/announceAttached,
# 06-rows.js videoFirstFrame/grantVideoFile/openVideoFile). This replaces
# #124's "attach as a comment": no comment is made any more.
#   * every picture and every video is an item of its own, added after the
#     ones there (the cover only when the gallery is empty); a video's link
#     is a line under the gallery, never in the words;
#   * a video link pasted on its own into a scene with no picture gives the
#     Image section a placeholder tile with a play badge; the toast says
#     "Video added to scene N" and its Undo takes it back;
#   * words with a picture and a video card: the words go in, the picture
#     and the video each a tile, all ONE undo entry; a second picture goes
#     beside the first, and a video into a scene with pictures gets a tile
#     of its own too;
#   * a video link inside other words stays in them, and is added too;
#   * a picture file (with the HTML naming it on the web) is one picture; a
#     video file into an empty scene gets its first frame as the thumbnail
#     (a real webm made here), with its name under it; on desktop (the fake
#     bridge) the file is granted, and its name and its thumbnail open it;
#   * a picture only linked to the web cannot be kept, and a toast says so;
#   * drops: onto the words, and anywhere on the visual column — a picture
#     added beside the others, a video file as a tile, any other file
#     refused with a toast;
#   * the toast's Undo refuses once something else was done.
# Every `eval` is one physical line.
