# The b-roll panel and the full-page shot list in a review session (#30,
# #148, #150; src/js/08d-broll-panel.js): the list to read, not to change.
#
# A reviewer's edits to the list are never kept by the server, so before
# this they looked as if they had worked and were then lost. Now:
#
#   * the checkbox, the status, the flag and the assignee are drawn
#     disabled (their values still readable); the note is read-only; the
#     location picker, + Person, Add prop, a prop's ×, the Cuts against
#     pencil and the ⋯ menu are not drawn; Add a shot and the bulk bar are
#     hidden, and Ctrl+click opens a line like a plain click and selects nothing;
#   * a control forced back into the page is refused by the panel's own
#     click, change, focusout and Enter handlers, with the "Viewing only"
#     toast, and the record is left as it was — the guard, not the CSS,
#     and not the body class either;
#   * opening a shot, the filter chips, the Group menu, Go to scene, and on
#     the full page its grouping, CSV and Print shot list all still work;
#   * the same document as an editor gets every control back.
# Like 43-review-mode.txt, the role comes from window.__hostedTest.setSession
# (the harness cannot start server.js). Every `eval` is one physical line.
