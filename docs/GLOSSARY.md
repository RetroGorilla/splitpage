# Glossary

These are the agreed terms and numbering rules for the terminology change. They describe the intended experience; existing screens may use older wording until the change is complete.

- **Video:** the whole script.
- **Scene:** a section of a video, containing beats.
- **Beat:** a unit within a scene. A beat can contain several shots, or be as long as one shot.
- **Shot:** a piece of footage within a beat. B-roll tags can list the shots in a beat.
- **Filmed:** the production status meaning a beat or shot has been filmed. "Shot" names footage, not this status.

## Numbering

Scenes use letters, continuing after Z as AA, AB, AC and so on. Beats use numbers that restart in each scene. Shots use numbers in the order of B-roll tags in their beat. For example, **B.8.4** is scene B, beat 8, shot 4. Within scene B, **8.2** means beat 8, shot 2; use the full form wherever the scene is not clear.

Every beat belongs to a scene. Beats before the first scene header belong to an automatic, unnamed Scene A. If the first header begins at the first beat, that header is Scene A and there is no empty automatic scene. An empty video has no scene until its first beat exists.

Numbers change when scenes or beats move. Plain-text references in comments and notes must be updated by the user. References that follow scenes or beats automatically, including their typing syntax, are deferred to collaboration work.
