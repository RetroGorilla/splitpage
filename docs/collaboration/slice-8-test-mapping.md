# Slice 8 app test mapping

The old sources are at [d5b45153b](https://github.com/RetroGorilla/splitpage/tree/d5b45153b). Braced values denote generated families. The re-audit keeps a case when its replacement lacks a combined assertion, an outcome needs an owner decision, or a live legacy mutation still depends on it. Retained counts refer to cases still in the test runner. The standard test build exposes native-only `__sharedTest`. Tests that still need the old session open it directly, or use `__legacySharedTest` from the separate legacy test fixture.

The dispositions use **(a)** for matching native assertions, **(b)** for native assertions added here, **(c)** for an intentional and documented difference with native coverage, and **(d)** for retired test mechanisms without a user-visible dependency. **Retained** means the old assertions still run.
