# Slice 8 app test mapping

The old sources are at [d5b45153b](https://github.com/RetroGorilla/splitpage/tree/d5b45153b). Braced values denote generated families. The re-audit keeps a case when its replacement lacks a combined assertion or its different outcome needs an owner decision. Retained tests run with their original assertions. The standard test build exposes native-only `__sharedTest`. Tests that still need the old session open it directly, or use `__legacySharedTest` from the separate legacy test fixture.

The dispositions use **(a)** for matching native assertions, **(b)** for native assertions added here, **(c)** for an intentional and documented difference with native coverage, and **(d)** for retired test mechanisms without a user-visible dependency. **Retained** means the old assertions still run.

## Peer insertion inside a pending split

The old case first shows `abcdef` on both copies. The editor buffers `X` at offset 3 and selects offsets 2–5 in `abcXdef`. The peer inserts `Z` at its offset 3, so its own text is `abcZdef`. The update is delivered before the editor presses Alt+Enter (Split) or Enter (native Writer), while the editor projection is still held. On the old backend the origin and peer converge on `ab`, `Zef`, `Other`, `Third`. Native Split and Writer both converge on `ab`, `ef`, `Other`, `Third`. The selected original letters and the pending `X` are removed in both cases. Only the native run removes the peer's `Z`.

[Section 2, Stale selections](native-adapter-design.md#2-what-each-command-writes) says a resolved selection with an original letter covers peer text inserted inside it. [Appendix H](native-adapter-design.md#h-outcomes-that-lose-nothing) says peer text survives a concurrent delete-and-split. The native adapter test `delete and split against concurrent type` in [delete-and-split.test.ts](../../tests/adapters/collab/native/delete-and-split.test.ts) applies both commands independently before exchange and then checks both delivery orders. Neither passage explicitly accepts removing a peer character delivered into a pending editor split before it is painted. The exact old schedule stays in `shared-split-callers-boundaries-app.test.mjs`. The observed native sequence stays in `shared-native-pending-structure-app.test.mjs` pending the owner's decision.
