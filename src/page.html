Import a script

Paste a script below, or choose a .docx, .md, .txt or .csv file. A single-column script becomes Audio text, ready for Visual notes; a two-column script (a table, tab-separated, or VISUAL:/AUDIO: labeled lines) is detected automatically and split into both columns. Unlike File ▸ Open — which starts a new document — this keeps the document you are in: its breakdown, cast list, b-roll and comments all stay, so it is the way to bring in a revised draft of the same script.

Import from Google Doc

Paste the link to a Google Doc (or just its ID). Splitpage can't read it directly — it opens Google's own Word (.docx) export of the doc in a new tab, which downloads it to your computer. Once it lands, bring it in the same way as any other Word file: File ▸ Open a document…. If the doc isn't shared "Anyone with the link", make sure you're signed in to the right Google account in that tab first.

Google Drive files

Browse, upload, rename, and delete files in any publicly shared Google Drive folder, straight from here — separate from opening and saving your script.

Browse your Google Drive, download files to this computer and upload files to it — separate from opening and saving your script. You sign in once, in your own browser; Splitpage keeps the sign-in, never your password.

Google Drive needs a Google Cloud OAuth client ID of type Desktop app, with the Google Drive API enabled. Put it in a file at

— the JSON file Google Cloud Console lets you download for the client works as it is, or write {"client_id": "…", "client_secret": "…"} — or set the environment variables before starting Splitpage. Then open this again. File ▸ Help, under “Google Drive files”, has the steps.

Google requires a project of your own for this: an API key to read a public folder, and an OAuth Client ID to make changes to it. Both are free, and only ever leave this browser to talk to Google's own APIs.

  1. Open Google Cloud Console and enable the Google Drive API for a project (create one if needed).
  2. Under APIs & Services ▸ Credentials, create an API key and paste it below.
  3. Also create an OAuth client ID (type: Web application), add this page's address as an Authorized JavaScript origin, and paste that Client ID below too.

Servers

A server is someone's shared session — theirs or your own. Add its address once and this browser remembers it. Splitpage never stores a password or an SSH key; a join PIN is kept only for as long as this tab is open unless you ask otherwise.

Add a server

The address above should then be http://localhost:<port here>/. Splitpage does not run ssh for you and keeps no key or password — it writes the command out for you to run.

Splitpage is a two-column visual/audio script editor with a
          built-in teleprompter. Scripts save as readable Markdown (.md)
          files by default — a table you can read and edit anywhere, with everything
          Splitpage needs kept alongside it — or as Splitpage's own native
          .splitpage format, which is exactly what it looks like
          internally, if you would rather have zero translation.
